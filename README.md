# Lista de Tarefas - API REST + Front-end

Aplicação full-stack para gerenciamento de tarefas com autenticação simples e isolamento de dados por usuário.

## Tecnologias Utilizadas
- **Backend:** Node.js, Express, PostgreSQL, `pg`, `dotenv`, `cors`
- **Frontend:** HTML5, JavaScript (Fetch API)
- **Banco de Dados:** PostgreSQL

## Funcionalidades
- Cadastro e Login de usuários
- Validação de campos obrigatórios
- CRUD completo de tarefas (Criar, Listar, Atualizar e Deletar)
- Isolamento de tarefas por ID de usuário no banco de dados
